Hướng Dẫn Sử Dụng Bot RPA

Phần 1: Tải và Cài đặt Môi trường

  • Tải file cài đặt môi trường Node.js tại đây: Link tải
  • Sau khi tải xong, mở file lên và bấm cài đặt (chỉ cần ấn Next đến khi hoàn tất).

Phần 2: Tải và Giải nén Dữ liệu Bot

  • Tải file nén dữ liệu bot (file .rar) tại đây: Link tải
  • Copy file nén vừa tải vào thẳng ổ C (hoặc ổ D).
  • Giải nén trực tiếp ngay tại đó. Lưu ý: Tuyệt đối không tạo thêm thư mục con. Sau khi giải nén, anh phải thấy ngay thư mục chứa code ở ổ C, ví dụ: C:\bot_baocao.

Phần 3: Thiết lập Thư viện (Chỉ làm ở lần đầu tiên cài máy)

  • Ấn tổ hợp phím Windows + R, gõ cmd rồi bấm Enter để mở cửa sổ dòng lệnh màu đen.
  • Điều hướng vào thư mục con Bot. Cần đảm bảo con trỏ nhấp nháy của anh đang ở đúng dòng: C:\bot_baocao> (hoặc D:\bot_baocao nếu để ở ổ D - trên CDM gõ lệnh "D:"). (Nếu CMD đang ở ổ khác ví dụ c:\users\admin> hoặc D:\ , hãy gõ cd C:\bot_baocao hoặc cd D:\bot_baocao và Enter để di chuyển tới).
  • Gõ lệnh sau và bấm Enter để khởi tạo file cấu hình quản lý thư viện:
    npm init -y
  • Gõ tiếp lệnh sau và bấm Enter để tải các thư viện bắt buộc:
    npm install puppeteer @supabase/supabase-js keypress
  • Gõ lệnh sau và bấm Enter để tải trình duyệt Chrome ẩn:
    npx puppeteer browsers install chrome

Phần 4: Cách Chạy Bot Báo Cáo Hàng Ngày

  • Trên bảng điều khiển (Website HTML), mở thanh menu bên trái. Chọn Từ ngày - Đến ngày cần quét dữ liệu.
  • Bấm nút Lấy Lệnh và nhập mã PIN. Hệ thống sẽ tự động tạo lệnh và Copy vào bộ nhớ máy tính.
  • Chuyển qua màn hình đen CMD (phải đang ở dòng C:\bot_baocao>).
  • Ấn Ctrl + V (hoặc Click chuột phải) để dán đoạn lệnh vừa lấy.
  • Ấn Enter để bot tự động bật trình duyệt và chạy.
  • Lưu ý: Ở những ngày tiếp theo, anh bỏ qua toàn bộ Phần 1, 2, 3 và chỉ cần lặp lại thao tác tại Phần 4.
