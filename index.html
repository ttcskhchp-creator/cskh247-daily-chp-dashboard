Hướng Dẫn Sử Dụng Bot RPA

Phần 1: Tải và Cài đặt Môi trường

  • Tải file cài đặt môi trường Node.js tại đây: Link tải
  • Sau khi tải xong, mở file lên và bấm cài đặt (chỉ cần ấn Next đến khi hoàn tất).

Phần 2: Tải và Giải nén Dữ liệu Bot

  • Tải file nén dữ liệu bot (file .rar) tại đây: Link tải
  • Copy file nén vừa tải vào thẳng ổ C (hoặc ổ D).
  • Giải nén trực tiếp ngay tại đó. Lưu ý: Tuyệt đối không tạo thêm thư mục con. Sau khi giải nén, anh phải thấy ngay thư mục chứa code ở ổ đĩa, ví dụ: C:\bot_baocao.

Phần 3: Thiết lập Thư viện (Chỉ làm ở lần đầu tiên cài máy)

  • Chạy file PhanMem_CSKH.bat trong thu mục giải nén, gõ số 3 để mở cửa sổ dòng lệnh màu đen và chạy môi trường khởi tạo Bot.
  • Điều hướng vào thư mục con Bot. Cần đảm bảo con trỏ nhấp nháy đang ở đúng dòng: C:\bot_baocao> (hoặc D:\bot_baocao nếu để ở ổ D).
    (Nếu CMD đang ở ổ khác ví dụ c:\users\admin>, hãy gõ cd C:\bot_baocao hoặc gõ D: rồi cd D:\bot_baocao và Enter để di chuyển tới).

Phần 4: Cách Chạy Bot Báo Cáo Hàng Ngày

  • Trên Dashboard, mở menu bên trái. Chọn Từ ngày - Đến ngày cần quét dữ liệu ở mục "Cào Dữ Liệu Bot".
  • Bấm nút Cào Dữ Liệu Bot và nhập mã PIN 6xxx. Hệ thống sẽ tự động tạo lệnh và Copy vào bộ nhớ máy.
  • CHẠY FILE .BAT trong thư mục GIẢI NÉN RAR bot_baocao và làm theo hướng dẫn hoặc Mở cửa sổ CMD (phải đang ở dòng C:\bot_baocao>). Ấn Ctrl + V để dán lệnh vừa lấy và ấn Enter.
  • Lưu ý quan trọng về Chrome: Bot sẽ tự động mở Chrome và ép cấu hình màn hình rộng 1920x1080 kết hợp thu nhỏ (zoom out) 75% để nhìn thấy bao quát toàn bộ trang web mà không bị che lấp nút bấm. Tuyệt đối không tự ý bấm thu nhỏ cửa sổ Chrome xuống thanh Taskbar trong lúc bot đang chạy.
  • Mẹo: Ấn tổ hợp phím Ctrl + P tại màn hình đen CMD bất kỳ lúc nào để Tạm Dừng hoặc Chạy Tiếp bot.
  • Ở những ngày làm việc tiếp theo, anh bỏ qua Phần 1, 2, 3 và chỉ cần làm Phần 4.
